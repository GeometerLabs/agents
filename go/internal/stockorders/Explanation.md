# internal/stockorders: the Stock orders shop in Go

The Go twin of `templates/commerce/stock-orders` (read its README first: the owner asks for a reorder, the agent builds the exact order from the approved supplier list and the
catalogue, the owner approves THAT on a card, the month's budget is reserved with the approval, the order goes to the supplier once, and the supplier's OK, the delivery and the
payment note are three different records). It is a `runtime.Kit`: the queue, the record, the owner's sign-in, passkeys, push, the limits page and the HTTP face are the shared
runtime's. `cmd/stock-orders` runs one shop from the same folder as `server/main.ts`.

## Send once

The step never sends the purchase order. `queueOrder` records an intent in the store (`sendOnce`), saved with the step. The shared runtime then calls the agent's `AfterSave`
(`internal/runtime/kitstock.go`, added for this template: core.ts runs `agent.sendOnce.run` after every step and beat), which is `messaging.RunSendOnce` with this template's
deliver, settle and notify: claim, save, send, ending, save. A claim found with no ending is never sent again; the owner's page asks "They got it" / "Send it again".

## The shop's stock count

The count is `internal/stock`, shared with listings and Orders. A delivery the owner marks raises a counted supply item once per purchase order by the total received so far
(`ReconcileDeliveries`); a count that falls to its low mark starts one reorder per crossing through the same `settle` as the owner's own "low shampoo".
